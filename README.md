# The Unfinished Promise

This is a browser game where you choose your own path, and it is about the civic virtue of **justice** and the value of **equality**. We made it for a Civic Virtues project in English and U.S. History.

You make the decisions at real turning points in America's fight over "all men are created equal," which are the Declaration in 1776, the compromises in the Constitution in 1787, the 14th Amendment in 1868, *Plessy v. Ferguson* in 1896, and *Brown v. Board* in 1954, and you see how close the country gets to the promise it started with. Every choice changes what happens next and moves a "Promise of Equality" meter, so the story can end anywhere from *A More Perfect Union* to *The Promise Betrayed*.

## Play it
- **Online:** https://nishanthnagarajan6-art.github.io/unfinished-promise/
- **Offline:** download `index.html` and open it in any browser, since it really does not need an install or an internet connection.

## Presenter mode for class votes
Press `P` or use the toolbar button to switch to classroom mode, which gives you larger text, keyboard navigation, vote tallies for each option, hand counts for the quizzes, and a CSV or JSON export of the results.

## Sources
The Morris and Madison quotes are copied word for word from the Constitution, the Federalist Papers, the Bill of Rights, and the records of the Convention, and every historical claim is cited on the Sources page inside the game.

The whole game is one self-contained file written in plain HTML, CSS, and JavaScript.
