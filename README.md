# The Unfinished Promise

A browser-based choose-your-path game about the civic virtue of **justice** and the value of **equality**, made for a Civic Virtues project (English / U.S. History).

You make the call at real turning points in America's fight over "all men are created equal" — the Declaration (1776), the Constitution's compromises (1787), the 14th Amendment (1868), *Plessy v. Ferguson* (1896), and *Brown v. Board* (1954) — and see how close the country comes to the promise it started with. Every choice changes what happens next and moves a "Promise of Equality" meter, so the story can end anywhere from *A More Perfect Union* to *The Promise Betrayed*.

## Play it
- **Online:** https://nishanthnagarajan6-art.github.io/unfinished-promise/
- **Offline:** download `index.html` and open it in any browser. No install, no internet needed.

## Presenter / class-vote mode
Press `P` (or use the toolbar button) for classroom mode: larger text, keyboard navigation, per-option vote tallies, quiz hand-counts, and CSV/JSON export of the results.

## Sources
Every Morris and Madison quote is the exact wording of the Constitution, the Federalist Papers, or the founders' own recorded words, and every historical claim is cited on the Sources page inside the game.

Built as a single self-contained file with plain HTML, CSS, and vanilla JavaScript.
